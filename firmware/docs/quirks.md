# Firmware quirks

Generated by `firmware/tools/gen_quirks_doc.py` from `firmware/config/quirks.def`.
Do not edit by hand.

Each quirk is a stock Begode Extreme behaviour that the **compat** profile reproduces, so our
image can run in lock-step with the stock binary. The **clean** profile fixes it unless the
Clean column says `on`. Code tests a quirk with `if (EUC_QUIRK(ID))`; target images resolve it
at compile time, the SIL library at run time so the studio can switch one quirk at a time.
The bit is the quirk's position in the SIL mask.

## Attitude estimation and numerics

| Bit | ID | Compat | Clean | Stock reference | Summary |
|---|---|---|---|---|---|
| 0 | `ASIN_ACCEL` | on | off | 0x080037A8 ahrs_update | Each low-passed accelerometer axis goes through asin() before the Mahony normalisation. |
| 1 | `SEQ_QUAT_UPDATE` | on | off | 0x080037A8 ahrs_update | The quaternion is integrated in place, so q1..q3 use components already updated in this step. |
| 2 | `FAST_INV_SQRT` | on | off | 0x080070AC invSqrt | Normalisation uses the 0x5F3759DF inverse square root with one Newton step. |
| 3 | `KEIL_FTZ` | on | off | Keil soft-float library (every float and double operation) | Float and double results that would be denormal are flushed to zero, as in the Keil library. |
